 Trend Detection on Social Media using Machine Learning & Deep Learning

Project Description
This project aims to detect trending topics from social media posts using Machine Learning and Deep Learning techniques. 
The system analyzes text data, groups similar posts, and identifies the most frequent topics as trends.

 Objectives
- To preprocess and clean social media text data
- To extract important features using TF-IDF
- To group similar posts using KMeans clustering
- To detect trending topics automatically
- To classify new posts using LSTM (Deep Learning)

Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- TensorFlow / Keras
- Matplotlib

Modules Implemented
 1. Data Preprocessing
- Cleaning text (removing special characters, stopwords)

 2. Feature Extraction
- TF-IDF vectorization to convert text into numerical format

 3. Clustering
- KMeans algorithm used to group similar posts

 4. Trend Detection
- Most frequent cluster is identified as trending topic

 5. Sentiment Analysis
- TextBlob used to calculate sentiment polarity

 6. Deep Learning Model
- LSTM used to classify and predict topic of new posts

 7. Visualization
- Scatter plot for clusters
- Pie chart for cluster distribution

 Output
- Clustered posts
- Trending topic identified
- Sentiment values
- Visualization graphs

 Conclusion
The project successfully detects trending topics by analyzing and grouping similar posts. 
Deep learning enhances prediction capability for new incoming data.
